# The Silent Lion

A browser-based narrative mystery investigation game. See `/docs` for
design documentation (canonical) and `/docs/engineering` for architecture
decisions.

Phase 1 status: framework scaffolding with a placeholder vertical-slice
scene. No final story content yet — see `/docs/CLAUDE.md` for the
engineering charter.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run test     # run the Vitest suite
npm run build    # type-check + production build
```
